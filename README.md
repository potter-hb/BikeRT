# BikeRT

骑行守门员是一个面向 Android 的个人共享单车骑行辅助工具。用户只需点击一次，即可打开美团扫码，开始 50 分钟骑行计时，并在到期后尝试进入骑行订单、点击关锁和核验还车结果。

> 当前状态：开发测试版。自动操作依赖美团当前页面结构，尚未完成所有真实骑行场景验证。

## 功能

- 一键打开美团并尝试进入扫码页面。
- 50 分钟后台倒计时和锁屏通知。
- 到期后保留并切回美团当前任务。
- 通过 Android 无障碍服务识别骑行订单和关锁按钮。
- 最多尝试关锁 3 次，并在成功后核验结果。
- 无法确认关锁时发送声音、震动和高优先级通知。
- 控制中心“50分钟骑行”快捷开关。
- 无障碍服务诊断、重启/更新原因记录和关闭提醒。
- 无需 Root、服务器或第三方自动化运行时。

## 安全边界

应用只处理明确允许的页面文字，不使用固定屏幕坐标盲点。

- 只操作美团包名 `com.sankuai.meituan`。
- 广告只允许点击“跳过”或“跳过广告”。
- 不点击含义泛化的“关闭”或“确认”。
- 页面不匹配时停止自动操作。
- 不绕过验证码、支付、实名认证或其他安全校验。
- 不申请网络权限，骑行状态和诊断记录仅保存在本机。

## 技术架构

```text
MainActivity
├── 一键开始、倒计时、取消和状态展示
└── SettingsActivity
    ├── 无障碍、通知、精确闹钟和电池设置
    ├── 控制中心开关
    ├── 20 秒流程测试
    └── 无障碍诊断

RideTimerService
├── 前台计时
├── AlarmManager 到期触发
└── 成功或失败状态收口

RideAccessibilityService
├── AccessibilityNodeInfo 控件树遍历
├── 页面文字匹配
├── 可点击父控件查找
└── 扫码、跳过广告、进入订单、关锁和结果核验

ServiceHealthJobService
└── 每 15 分钟检查无障碍是否被系统关闭
```


```text
app/build/outputs/apk/debug/app-debug.apk
```

## 安装后设置

1. 安装 APK。
2. 打开应用并允许通知。
3. 在设置页开启“无障碍自动操作”。
4. 允许精确闹钟。
5. 将电池设置设为“不限制”，并允许自启动。
6. 对侧载安装的 Android 版本，在应用信息中检查“允许受限设置”。
7. 可把“50分钟骑行”添加到控制中心。

## 已知限制

- 美团没有开放骑行控制 API，本项目通过无障碍页面操作实现。
- 页面改版后需要更新控件文字或页面识别规则。
- Android 和手机厂商可能出于安全原因关闭无障碍服务，应用无法自行重新开启。
- 静音、勿扰模式和厂商后台策略会影响提醒效果。
- 调试 APK 仅用于测试，不应作为正式发布包分发。
